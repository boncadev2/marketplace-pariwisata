# Glosarium

| Istilah | Arti |
| --- | --- |
| Destinasi | Tempat wisata yang memiliki halaman informasi; dapat gratis atau terkait produk berbayar. |
| Mitra | Usaha atau kelompok pengelola yang menawarkan konten atau produk. |
| Produk | Item yang dapat dipesan, seperti tiket atau paket wisata. |
| Paket desa | Produk perjalanan dengan itinerary berurutan yang menghubungkan beberapa titik wisata. |
| Quote | Perhitungan harga oleh server, lengkap dengan masa berlaku dan rincian komponen. |
| Hold inventori | Penahanan kuota sementara yang memiliki batas waktu. |
| Booking | Alokasi kuota yang sudah terkonfirmasi sesuai aturan domain. |
| Departure | Keberangkatan paket pada tanggal tertentu dengan kapasitas, cutoff, dan status operasional. |
| Voucher | Bukti hak layanan setelah pembayaran dan layanan memenuhi syarat, biasanya dengan QR/token acak. |
| Settlement | Proses penyelesaian kewajiban dana kepada mitra sesuai kontrak/provider. |
| Refund | Pengembalian dana yang dihitung dari kebijakan versi pesanan dan dikonfirmasi penyedia pembayaran. |
| Pilot | Peluncuran terbatas pada satu kabupaten untuk memvalidasi alur dan operasi. |
