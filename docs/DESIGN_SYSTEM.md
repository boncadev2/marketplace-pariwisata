# Design System Awal

Frontend menggunakan JavaScript dan token CSS pada `frontend/src/app/globals.css`.

| Token | Peran |
| --- | --- |
| `--brand` | Aksi utama dan identitas hijau wisata |
| `--ink` | Teks utama |
| `--muted` | Teks pendukung |
| `--line` | Batas input dan kartu |
| `--surface` | Latar halaman |
| `--radius` | Radius konsisten kartu dan panel |

Komponen awal: navigasi, tombol, input, select, kartu, placeholder galeri, ringkasan fakta, dan footer. Wireframe tersedia pada halaman `/`, `/destinasi`, `/destinasi/demo`, `/paket`, `/paket/demo`, `/checkout`, serta `/akun`.

Semua halaman ini menggunakan fixture demonstrasi. Tombol pemesanan sengaja tidak aktif sampai fase transaksi selesai.
